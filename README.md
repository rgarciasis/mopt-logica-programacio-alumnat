# Lògica i Programació · web de l’alumnat

Distribució pública del mòdul optatiu de 1r d’SMX.

## Publicació a GitHub Pages

Puja **el contingut d’aquesta carpeta** a l’arrel del repositori, de manera que `index.html` quedi al mateix nivell que `README.md`. A GitHub, configura **Settings → Pages → Deploy from a branch → main → /(root)**.

Aquesta distribució no conté guies docents, solucionaris ni recursos restringits.
